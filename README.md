# Guru AI — Total Advanced Personal Assistant

**Guru AI** tera apna advanced Android AI assistant hai.

## ✅ Features (Total Advanced)

### Core
- Gemini + Grok API keys (Settings mein boxes)
- Automatic fallback (agar ek fail ho to doosra)
- Preferred provider select (Gemini / Grok)
- Online / Offline mode toggle

### Chat
- Modern dark UI with bubbles
- Chat history save (persistent)
- Auto conversation summarization
- Copy button on AI replies
- Typing indicator

### Memory & Knowledge
- Save notes (Guru yaad rakhega)
- Relevant notes auto-inject in replies
- Clear history

### Agent Tools
- Current time tool
- Web Search tool (Google Custom Search API optional)

### Voice (structure ready)
- Mic permission + SpeechRecognizer support prepared
- TTS (Text-to-Speech) toggle in Settings

### Themes
- 4 premium themes (Midnight Gold, Deep Purple, Ocean, Forest)

### Extra
- Status bar (keys + mode)
- Camera / File provider ready
- Clean Compose + Material 3

## Setup

1. Android Studio mein open karo
2. Gradle sync
3. Settings mein **Gemini** ya **Grok** API key daalo
4. Run

### API Keys
- Gemini → https://aistudio.google.com
- Grok → https://console.x.ai

### Optional (Web Search)
Google Custom Search API key + CX daal sakte ho Settings mein.

## Note

WhatsApp Notification Listener, Accessibility Service aur full Gmail OAuth ke liye extra system permissions + services chahiye. Unka structure baad mein add kiya ja sakta hai.
